# Setting up a grant or an event

Tools: `get_workspace_guide`, `list_spaces`, `list_work_packages`, `create_space`, `create_work_package`,
`create_task`, `get_space_access`.

1. Read the guide: where a new grant or event goes, its standard subfolders, naming, who should see it.
2. Check what exists (`list_spaces`, `list_work_packages`) so nothing is duplicated.
3. Ask for what is missing: the name, the main deadline, the people involved.
4. Propose the set-up in one view: the folder and its subfolders, who will see them (new subfolders inherit the
   folder's access), the work package, and the milestone, deliverable and deadline tasks with dates.
5. On a yes, create in that order: `create_space` (folder, then subfolders), `create_work_package`, `create_task`.
6. Show what was made with the activity ids; `undo_change` on each reverts it.
